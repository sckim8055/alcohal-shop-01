## 다음 차례: 구매자 마이 화면 (쿠팡 MY쿠팡 구조 참고)

- 취소·반품·교환 신청과 내역: 구매자가 사유를 적어 신청, 판매자가 승인·거절, 승인 시 환불 기록과 연결
- 리뷰: 구매 확정한 상품에 별점·글·사진, 상품 화면에 표시, 판매자 답글
- 찜: 상품 찜하기와 찜 목록
- 배송지 관리: 여러 배송지 저장, 기본 배송지, 주문 화면에서 고르기
- 다시 담기: 주문한 상품을 장바구니에 다시 담기
- 회원 탈퇴: 진행 중인 주문이 없을 때만, 개인정보 지우기
- 문의: 상품 문의(상품 화면에 공개·비공개), 주문 문의(판매자에게), 1:1 문의(운영자에게), 판매자·운영자 답변 화면
- 최근 본 상품

## 그다음: 할인과 행사

- 판매자 쿠폰: 금액·비율 할인, 최소 주문 금액, 기간, 수량 제한. 대금이 판매자에게 직접 가는 구조라 할인 비용은 판매자가 부담하는 것만 가능하다.
- 기획전: 운영자가 상품을 묶어 보여 주는 화면과 첫 화면 띠
- 시간 한정 할인(타임세일), 묶음 할인
- 무료배송 행사 기간 테스트 추가

## 실제 판매 전에 반드시

- 성인인증: 본인확인 서비스 연동(지금은 생년월일 입력만 확인)
- 배송 조회: 배송 조회 서비스 연동(지금은 가짜 데이터)
- 메일·문자·알림톡 발송: 지금은 보낼 내용만 쌓인다(message_outbox). 메일은 SMTP 계정, 문자·알림톡은 발신번호 등록과 카카오 비즈니스 채널이 필요하다.
- 약관·개인정보처리방침·통신판매중개자 고지, 판매자 정보 표시(상호, 대표자, 주소, 통신판매업 신고번호)
- 주류 통신판매 기준 확인(국세청·세무사), 구매안전서비스 요건 확인
- 비밀번호 찾기, 가입 시 이메일 확인
- 운영자 계정 만들기 절차(시범 계정 끄기)
- Spring Security 적용 검토, MySQL 에서 전체 테스트, HTTPS 설정
- 올린 파일을 저장소 서비스로 옮기기, 사진 크기 줄이기(썸네일), 쓰지 않는 파일 정리
- 로그인 세션 저장소(서버 여러 대), 백업, 접속 기록, 오류 알림
- 운영자 활동 기록(누가 언제 회원을 정지했는지 등)
