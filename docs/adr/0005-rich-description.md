# 0005. 상품 상세설명 편집기를 넓히고 HTML 은 블록으로 바꿔 가져온다

날짜: 2026-11-28

## 결정

- 상세설명은 지금처럼 편집기 문서(JSON)로 저장한다. HTML 을 그대로 저장하거나 보여 주지 않는다.
- 다른 몰(쿠팡, 스마트스토어 등)에 쓰던 HTML 은 "HTML 붙여 넣기"로 넣으면 편집기 블록으로 바뀐다(네이버 스마트에디터 ONE 과 같은 방식). 바꾸지 못한 꾸밈(글꼴, 겹친 배치, 테두리 등)은 빠지고, 빠진 사진·동영상 수를 판매자에게 알린다.
- 외부 링크와 외부 사진(https)은 허용한다(운영자 결정). 외부 사진은 원래 사이트가 지우거나 막으면 보이지 않으므로 편집기에서 알린다. 외부 사진에는 이 사이트 주소(referrer)를 넘기지 않는다.
- 동영상은 이 사이트에 올린 것과 유튜브만. 유튜브는 영상 번호만 꺼내 youtube-nocookie 주소로 보여 준다.
- 서버는 허용 목록(블록 종류, 블록이 들어갈 자리, 주소 형식, 색·크기 형식, 사진 200장·동영상 20개)으로 검사한다.

## 추가한 블록

표, 직접 올린 동영상, 유튜브, 사진 묶음(나란히·옆으로 넘겨 보기), 강조 상자, 글 맞춤, 글자 색·크기(편집기는 정해진 몇 가지만, 가져온 글은 원래 값 유지).
편집기 도구: 블록 위·아래로 옮기기, 사진 끌어 넣기·붙여 넣기, 휴대폰 미리보기.

## 구현하면서 정한 것

- 사진·동영상·HTML 같은 큰 블록은 커서가 표 칸, 강조 상자, 목록 안에 있어도 그 블록 바깥(바로 아래)에 넣는다. 안에 넣으면 상세페이지 전체가 표 한 칸에 들어가 버린다.
- 넣은 블록 아래에 빈 줄을 두어 커서를 옮긴다. 블록이 선택된 채로 다음 것을 넣으면 선택된 블록이 바뀌어 사라진다.
- 도구 단추는 누를 때 편집기 포커스를 빼앗지 않는다. 빼앗으면 고른 글의 선택이 꼬여 다음 입력이 글을 덮어쓴다.
- 설명 안의 사진은 테두리·여백 없이 이어 붙인다(긴 사진 여러 장으로 만든 상세페이지가 한 장처럼 보이게).
- `<h1>` 은 큰 제목, `<h4>`~`<h6>` 은 작은 제목으로 바꿔 가져온다.

## 남은 것

- 사진을 서버에서 줄여 저장하기(지금은 원본 그대로, 5MB 까지). 긴 통이미지 상세페이지는 이것 때문에 막힐 수 있다.
- 기본 틀(전통주용), 상품정보제공고시 입력 칸.
- 외부 사진을 이 사이트로 복사해 오기(지금은 외부 주소 그대로 보여 준다).
